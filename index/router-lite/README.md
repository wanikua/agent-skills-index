# Router-Lite Shards

> **Purpose:** Zero-install Agent discovery with compact, grep-friendly skill metadata.

This directory contains sharded JSONL files for lightweight skill discovery without requiring the full `skills.jsonl` index or `atlas` CLI installation.

---

## File Organization

| File | Max Size | Content |
|------|----------|---------|
| `curated.jsonl` | 100 KB | Curated layer skills (highest quality) |
| `official.jsonl` | 100 KB | Official/vendor skills |
| `community-XX.jsonl` | 1 MB each | Community and unreviewed skills (sharded) |

All files contain **canonical skills only**. Duplicates, non-active skills, and malicious skills are excluded.

---

## Record Format

Each line is a compact JSON object with **short keys**:

```json
{"id":"github.com/owner/repo/path","n":"skill-name","d":"Description (≤200 chars)","kw":["keyword1","keyword2"],"tier":"official","lic":"MIT","sec":"pass","install":{"npx":"...","gh":"..."},"url":"https://...","h":"sha256:..."}
```

### Key Mapping

| Short Key | Full Name | Description |
|-----------|-----------|-------------|
| `id` | ID | Unique skill identifier (location-based) |
| `n` | Name | Skill name from frontmatter |
| `d` | Description | Truncated to 200 characters |
| `kw` | Keywords | Up to 12 TF-IDF extracted keywords |
| `tier` | Trust Tier | `official` \| `curated` \| `community` \| `unreviewed` \| `aggregator-copy` |
| `lic` | License | SPDX license identifier (or `NOASSERTION`) |
| `sec` | Security | Security status: `pass` \| `pending` \| `review` \| `warn` \| `error` |
| `install` | Install | Installation commands (`npx`, `gh`, etc.) |
| `url` | URL | Source repository URL |
| `h` | Content Hash | SHA-256 content hash with `sha256:` prefix |

## Usage Examples

### 1. Agent Discovery (Zero-Install)

```python
import urllib.request
import json

# Fetch curated skills
url = "https://raw.githubusercontent.com/wanikua/agent-skills-index/main/index/router-lite/curated.jsonl"
response = urllib.request.urlopen(url)

for line in response:
    skill = json.loads(line)
    if "pdf" in skill["kw"]:
        print(f"{skill['n']}: {skill['d']}")
        print(f"  Install: {skill['install'].get('npx', 'N/A')}")
```

### 2. Grep-Friendly Search

```bash
# Find skills related to PDFs
grep -iE '"kw":\[.*"pdf".*\]' curated.jsonl official.jsonl

# Find official skills with MIT license
grep '"tier":"official"' official.jsonl | grep '"lic":"MIT"'
```

### 3. Progressive Loading

Load `curated.jsonl` first (smallest, highest quality), then `official.jsonl`, then `community-*.jsonl` only if needed.

## Keyword Extraction

Keywords (`kw`) are extracted using **TF-IDF** from:
- Skill name (highest weight)
- Description (medium weight)
- Markdown titles (medium weight)
- Body text first 400 words (**only for `allow` / `conditional` licenses**, per ⚠️D5)

Filters applied:
- Length: 3-30 characters
- Stopwords removed (English + domain-specific boilerplate)
- High-frequency terms filtered by IDF score
- Maximum 12 keywords per skill

---

## Exclusion Rules

Skills are **excluded** from router-lite if:

1. **Not canonical** — `dedup.canonical_id` points to a different skill
2. **Status ≠ active** — Removed, quarantined, or dangling skills
3. **Security status = malicious** — Known malicious content

---

## License Compliance (⚠️D5)

Body text extraction respects license restrictions:

- **`allow` / `conditional` licenses:** Store first 400 words of body for keyword extraction
- **Other licenses:** Only store markdown title list (≤20) and keywords derived from name/description

This ensures router-lite shards comply with upstream license terms.
